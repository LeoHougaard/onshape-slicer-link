# Setup help

| Problem | Try this |
| --- | --- |
| Windows questions the installer | This test installer is unsigned. Check it came from this project's release page. Report the exact warning if you cannot open it. |
| I cannot find Developer in Onshape | Open your account icon, then **My account > Developer**. A managed account may require administrator help. |
| Onshape rejects the redirect address | Use **Connected Desktop App** and copy the redirect using the wizard's button. |
| I copied the wrong client details | Open **Slicer Link connection setup** from Windows Start. On Linux, use the application's **Connection setup** menu action. If the app is already connected, the same option is under **Connection & API use**. |
| The local page will not open | Start **Onshape Slicer Link** from your application menu. A browser bookmark does not start the app. |
| My slicer is missing | Open **Can't find your slicer?**, choose its name, browse to its installed executable or AppImage, then **Use this slicer**. |
| No parts appear | Choose an editable Part Studio containing a solid part. Assemblies, sketches, surfaces, and saved-version links are not supported by this flow. |
| The shape did not change | Wait for Send / Update, then **Reload from disk** on the existing object in your slicer. |
| Reload cannot find a file | Connect your saved `.3mf` again, then Send / Update. If asked, select the matching `.stl` beside that project. |

The wizard follows [Onshape's application registration steps](https://cad.onshape.com/help/Content/Plans/my_account_developer.htm).
Client details are generated by Onshape. Never share them or your account password.

## Arch password store

Slicer Link needs an unlocked desktop password store. If you already have one,
keep using it. For GNOME Keyring on Arch:

```sh
sudo pacman -Syu --needed gnome-keyring seahorse
```

This also updates your Arch system. Open **Passwords and Keys**, also called
Seahorse, and create or unlock a password keyring. Minimal desktops may need
additional startup configuration; see the [ArchWiki guide](https://wiki.archlinux.org/title/GNOME/Keyring).
KWallet compatibility with this package is unverified.

For AppImage permission errors, enable execution in the file's properties. If
the slicer reports missing FUSE, Arch provides `fuse2`.
[AppImage help](https://docs.appimage.org/user-guide/troubleshooting/fuse.html#setting-up-fuse-on-arch-linux).

## API limits

Slicer Link needs no paid hosting. Onshape API requests do count toward the
private connection owner's allowance. The app reuses exports and does not poll
CAD in the background. Check **My account > Developer** in Onshape for usage.
For error 429, wait before retrying. For 402, check the annual allowance.
[Onshape's limits](https://onshape-public.github.io/docs/auth/limits/).

## Report a problem

[Open an issue](https://github.com/LeoHougaard/onshape-slicer-link/issues) with
the step, error message, operating system, and slicer version. On Linux, include
your desktop environment. Crop account details and private CAD out of screenshots.

Logs and managed data are in `%LOCALAPPDATA%\OnshapeSlicerLink\local` on Windows
or `~/.config/onshape-slicer-link/local` on Linux, unless you set `XDG_CONFIG_HOME`.
Inspect `app.log` before sharing excerpts. Keep this folder when updating the app.
