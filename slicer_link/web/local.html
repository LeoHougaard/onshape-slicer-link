Link a part to send it to your slicer.

    New parts open in your slicer

    The app manages the source files automatically. After updating an existing part, select it in your slicer and use Reload from disk.

    Slicer Link cannot see unsaved slicer projects or confirm a reload. Your slicer controls placement, supports, slicing, and printing.

    Keep the link after reopening a saved project

    Save your project normally in the slicer, then connect its .3mf here. The app will keep source files beside it automatically so Reload from disk can find them.

    Start a new project or reopen missing parts

    This opens the selected parts again. It can add duplicates if they are already in your slicer.

    Connection & API use

    Onshape is contacted when you choose parts or send updates. There is no background CAD polling.

    Official, unmodified OrcaSlicer and Bambu Studio. No hosting subscription.
