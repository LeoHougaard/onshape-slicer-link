Onshape did not finish connecting

If you cancelled or waited too long

Open Onshape Slicer Link from your application menu to try signing in again. Keep your internet connection on and allow access when Onshape asks.

If your keys were rejected

On Windows, open Slicer Link connection setup from Start. On Linux, use the app launcher's Connection setup action.

In Onshape, open My account > Developer > OAuth applications, select your connection, then Keys and secret.

The wizard needs two different values from that same connection: the OAuth secret key and the OAuth client identifier key. Keys from the separate API keys tab will not work.

Use Back in the wizard to check the app type and redirect address too.
